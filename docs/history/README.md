# Historical records

Completed migration reports, superseded plans and point-in-time audits.

These are kept for provenance, not as current guidance. Nothing in this folder
is referenced by code, tests or CI, and none of it should be treated as
describing the system as it stands today. For that, see:

- `docs/SECURITY_REVIEW.md` — current security posture and open items
- `docs/PWA.md` — PWA architecture, deployment and versioning
- `ARCHITECTURE.md` — current architecture
- `ROADMAP.md` — forward-looking plan

Moved here from the repository root during a cleanup pass; the git history of
each file is preserved through the move.
